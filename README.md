# CoreUI

A small project that redesigns different parts of Roblox's CoreGui to make them look and feel cleaner.

## Currently Redesigned

- **Chat**
- **Leaderboard**
- **TouchGui** — Restyles the classic thumbstick to give it a more modern look.
